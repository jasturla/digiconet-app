# Repository guidance

## Project status

This repository is currently empty. No application framework, build system, or test suite has been established yet.

## Working in this repository

- Inspect the repository contents before making changes; do not assume a framework or invent project conventions.
- Keep changes focused on the user's request.
- When adding a project or tool, document the commands needed to install, run, and verify it in the relevant project documentation.
- Follow the conventions established by files added later, including formatting, naming, and test patterns.
- Do not add dependencies or generated artifacts unless they are needed for the requested work.
